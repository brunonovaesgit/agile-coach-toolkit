# Painel de sinais da transformação

Poucos sinais, ligados aos padrões, olhados todo mês na cadência com o patrocinador. Os limites abaixo são ilustrativos: ajuste com a linha de base medida no diagnóstico.

| Sinal | Padrão | Como medir | Linha de base | Acende o alerta quando | Mês 1 | Mês 2 | Mês 3 |
|---|---|---|---|---|---|---|---|

| Tempo de ponta a ponta | 1 e 4 | Mediana mensal, da ideia ao cliente | | Não melhora em três meses | | | |

| O que mudou para as pessoas | todos | Pulso quinzenal: "o que mudou de verdade no seu trabalho nas últimas duas semanas?" (1 a 5) | | Cai por dois ciclos seguidos | | | |

## Como ler
- Tendência, não foto: um mês ruim não é fracasso; dois ou três na mesma direção pedem conversa.
- Sinal leva a conversa, não a culpado: pergunte o que o sistema está mostrando.
- Quando um alerta acender, volte ao registro de riscos (arquivo 03) e revise a ação preventiva ligada a ele.
