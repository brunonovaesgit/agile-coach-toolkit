# Cartões dos seis padrões de fracasso

Imprima ou copie para o quadro. Use no pré-mortem (passo 5) e como autoavaliação rápida: para cada padrão, marque se ele está ausente, em formação ou instalado.

## 1. O framework vira o destino
- **Sinal:** O progresso é medido em squads criados, pessoas treinadas e cerimônias acontecendo.
- **Pergunta para o grupo:** Qual resultado de negócio esta transformação precisa mover? Como vamos saber?
- **O que fazer diferente:** Objetivo escrito como resultado, com medida e linha de base. Framework tratado como hipótese de meio.
- **Papel do coach:** Facilita

## 2. A transformação fica dentro da TI
- **Sinal:** Os times ágeis são de tecnologia; o negócio encomenda e espera.
- **Pergunta para o grupo:** Onde o negócio, o risco e as operações entram no fluxo?
- **O que fazer diferente:** Fluxo de valor de ponta a ponta; negócio e áreas de controle no desenho; revisões com decisão do negócio.
- **Papel do coach:** Lidera
- Situação hoje: ( ) ausente ( ) em formação ( ) instalado

## 3. Nomes novos, decisões antigas
- **Sinal:** Os cargos mudaram; quem decide e o ritmo das decisões, não.
- **Pergunta para o grupo:** Numa terça qualquer, o que essa pessoa faz de diferente?
- **O que fazer diferente:** Matriz de decisão antes e depois, revista com casos reais.
- **Papel do coach:** Facilita
- Situação hoje: ( ) ausente ( ) em formação ( ) instalado

## 4. As regras do jogo continuam as mesmas
- **Sinal:** Ciclos curtos com planejamento anual, aprovação projeto a projeto e incentivos de sempre.
- **Pergunta para o grupo:** Que regra atual contradiz o modelo novo?
- **O que fazer diferente:** Tornar visível com exemplo do fluxo; experimentos pequenos de governança e metas; donos das regras na transformação.
- **Papel do coach:** Contribui
- Situação hoje: ( ) ausente ( ) em formação ( ) instalado

## 5. A liderança patrocina de longe
- **Sinal:** A diretoria abriu a transformação e voltou a olhar só os indicadores antigos.
- **Pergunta para o grupo:** O que só a liderança pode fazer por esta mudança?
- **O que fazer diferente:** Backlog da liderança; cadência quinzenal com o patrocinador; líderes nas revisões.
- **Papel do coach:** Faz coaching
- Situação hoje: ( ) ausente ( ) em formação ( ) instalado

## 6. Copiar o modelo e lançar tudo de uma vez
- **Sinal:** Modelo de outra empresa, todas as áreas mudando na mesma data.
- **Pergunta para o grupo:** O que a primeira onda precisa nos ensinar?
- **O que fazer diferente:** Modelos como referência; ondas com critérios; hypercare depois de cada onda.
- **Papel do coach:** Contribui
