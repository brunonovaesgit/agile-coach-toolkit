# Backlog de transformação da liderança

Itens que só a liderança pode fazer. Escreva como hipótese: "Se [ação], então [resultado esperado]". Revise na cadência quinzenal com o patrocinador.

| # | Hipótese (se... então...) | Dono | Sinal de que funcionou | Prazo para avaliar | Situação |
|---|---|---|---|---|---|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |
| 4 | | | | | |

**Situação:** a fazer | em andamento | funcionou | não funcionou (ajustar).

## Perguntas para encontrar os itens
- Que indicador a diretoria acompanha hoje que puxa na direção contrária do novo modelo?
- Que decisão hoje sobe para nós e poderia ficar com os times?
- Em qual revisão de incremento a nossa presença mudaria uma decisão?
- Que meta ou incentivo precisa mudar para o novo comportamento valer a pena?

## Exemplo ilustrativo (Banco Fictício, investimentos)

| Hipótese | Dono | Sinal de que funcionou |
|---|---|---|
| Se a diretoria acompanhar o tempo de ponta a ponta no lugar do percentual de projetos no prazo, as prioridades vão refletir o cliente | Diretora de investimentos | Tempo de ponta a ponta na pauta de todas as reuniões mensais |
| Se houver uma alçada para mudanças pequenas, a espera pelo comitê cai | Diretora e governança | Espera média de mudanças pequenas abaixo de uma semana |
| Se os líderes participarem de uma revisão de incremento por mês, as decisões de negócio ficam mais rápidas | Gerentes da área | Decisões tomadas na própria revisão |
| Se as metas da área incluírem uma meta compartilhada por time, a colaboração aumenta | Diretora e RH | Meta compartilhada no próximo ciclo de avaliação |
