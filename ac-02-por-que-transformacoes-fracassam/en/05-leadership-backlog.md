# Leadership transformation backlog

Items only leadership can do. Write each as a hypothesis: "If [action], then [expected result]". Review in the biweekly sponsor cadence.

| # | Hypothesis (if... then...) | Owner | Sign it worked | Evaluate by | Status |
|---|---|---|---|---|---|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |
| 4 | | | | | |

**Status:** to do | in progress | worked | didn't work (adjust).

## Questions to find the items
- Which indicator do we track today that pulls against the new model?
- Which decision comes up to us today that could stay with the teams?
- In which increment review would our presence change a decision?
- Which goal or incentive must change for the new behavior to pay off?

## Illustrative example (Fictional Bank, investments)

| Hypothesis | Owner | Sign it worked |
|---|---|---|
| If the leadership team tracks end-to-end lead time instead of projects on schedule, priorities will reflect the customer | Head of investments | Lead time on the agenda of every monthly meeting |
| If there is a fast track for small changes, waiting for the committee will drop | Head of investments and governance | Average wait for small changes under one week |
| If leaders join one increment review a month, business decisions get faster | Area managers | Decisions made in the review itself |
| If area goals include one shared goal per team, collaboration increases | Head of investments and HR | Shared goal in the next evaluation cycle |
