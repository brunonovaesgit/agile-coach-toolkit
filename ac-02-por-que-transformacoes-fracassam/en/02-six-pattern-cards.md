# Six failure pattern cards

Print them or copy them to the board. Use them in the pre-mortem (step 5) and as a quick self-assessment: for each pattern, mark whether it is absent, forming or established.

## 1. The framework becomes the goal
- **Sign:** Progress is measured in squads created, people trained and ceremonies held.
- **Question for the group:** Which business outcome must this transformation move? How will we know?
- **What to do differently:** Goal written as an outcome, with a measure and baseline. Framework treated as a hypothesis about the means.
- **Coach's role:** Facilitates

## 2. The transformation stays inside IT
- **Sign:** Agile teams are technology teams; the business places orders and waits.
- **Question for the group:** Where do business, risk and operations enter the flow?
- **What to do differently:** End-to-end value stream; business and control functions in the design; reviews with business decisions.
- **Coach's role:** Leads
- Status today: ( ) absent ( ) forming ( ) established

## 3. New names, old decisions
- **Sign:** Titles changed; who decides and the pace of decisions did not.
- **Question for the group:** On any given Tuesday, what does this person do differently?
- **What to do differently:** Before-and-after decision matrix, reviewed with real cases.
- **Coach's role:** Facilitates
- Status today: ( ) absent ( ) forming ( ) established

## 4. The rules of the game stay put
- **Sign:** Short cycles with annual planning, project-by-project approval and the same incentives.
- **Question for the group:** Which current rule contradicts the new model?
- **What to do differently:** Make it visible with a flow example; small governance and goal experiments; rule owners in the transformation.
- **Coach's role:** Contributes
- Status today: ( ) absent ( ) forming ( ) established

## 5. Leadership sponsors from a distance
- **Sign:** Executives launched it and went back to the old indicators.
- **Question for the group:** What can only leadership do for this change?
- **What to do differently:** Leadership backlog; biweekly sponsor cadence; leaders in reviews.
- **Coach's role:** Coaches
- Status today: ( ) absent ( ) forming ( ) established

## 6. Copy the model and launch everything at once
- **Sign:** Another company's model, every area switching on the same date.
- **Question for the group:** What must the first wave teach us?
- **What to do differently:** Models as references; waves with criteria; hypercare after each wave.
- **Coach's role:** Contributes
- Status today: ( ) absent ( ) forming ( ) established
