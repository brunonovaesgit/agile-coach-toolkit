# Transformation signals dashboard

A few signals, tied to the patterns, reviewed monthly in the sponsor cadence. Thresholds below are illustrative: adjust them using the baseline measured during diagnosis.

| Signal | Pattern | How to measure | Baseline | Raise the alert when | Month 1 | Month 2 | Month 3 |
|---|---|---|---|---|---|---|---|
| Decisions still going to the old forum | 3 | Monthly count | | No drop after two months | | | |
| End-to-end lead time | 1 and 4 | Monthly median, idea to customer | | No improvement in three months | | | |
| Business deciding in reviews | 2 | % of reviews with a business decision | | Below 70% | | | |
| Leadership backlog moving | 5 | Items done in the month | | No items in a month | | | |
| Rules of the game under review | 4 | Governance or incentive experiments | | None by the end of wave 1 | | | |
| What changed for people | all | Biweekly pulse: "what really changed in your work in the last two weeks?" (1 to 5) | | Drops two cycles in a row | | | |

## How to read it
- Trend, not snapshot: one bad month isn't failure; two or three heading the same way call for a conversation.
- A signal starts a conversation, not a blame hunt: ask what the system is showing.
- When an alert goes off, go back to the risk log (file 03) and review the linked preventive action.
