# Transformation backlog

Each item is a hypothesis, not a task. Review it with the sponsor at the cadence of the coaching agreement. A hypothesis that is not confirmed is learning.

> We believe that **[change]** will result in **[outcome]**. We will know it worked when **[observable signal]**.

| Hypothesis (change) | Expected outcome | Signal that it worked | Status | Learning |
| --- | --- | --- | --- | --- |
| | | | | |

## Example (illustrative scenario: Fictional Bank)
| Hypothesis | Expected outcome | Signal that it worked |
| --- | --- | --- |
| Prioritize monthly instead of quarterly | Requests start earlier | Time in the prioritization queue drops by half |
| Create an approval level for small changes, without a committee | Simple changes reach customers faster | Small changes ship in days, not weeks |
| Leadership tracks end-to-end time every month | Decisions start to consider flow | The metric is on the monthly leadership agenda |
