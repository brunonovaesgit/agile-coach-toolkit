# First two weeks checklist

- [ ] Identify the level of work and the main mission
- [ ] Run the sponsor interview
- [ ] Fill in and validate the coaching agreement canvas
- [ ] Build the first sponsorship and influence map
- [ ] Pick a request and start following it
- [ ] Agree on the date of the first report back to leadership
