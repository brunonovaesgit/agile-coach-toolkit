## Exemplo (cenário ilustrativo: Banco Fictício)
| Campo | Cartões no Banco Fictício |
| --- | --- |
| Tipo de missão | Transformação |
| Cliente | Diretora de cartões (patrocinadora) e líderes das tribos de cartão |
| Situação atual | Organização por projeto; cada entrega passa por cinco áreas |
| Objetivo | Reduzir o tempo da ideia aprovada até o cliente |
| Como vamos medir | Tempo de ponta a ponta, acompanhado mensalmente pela diretoria |
| Dentro do escopo | Desenho dos fluxos de valor, fóruns, papéis ágeis, lançamento em ondas |
| Fora do escopo | Estrutura de cargos e salários, decisões de orçamento |
| Papéis | Patrocinadora decide; líderes de tribo co-desenham; coach facilita e propõe opções |
| Cadência | Revisão mensal com a patrocinadora; ponto semanal com os líderes |
| Critério de encerramento | Modelo rodando nas tribos de cartão, com líderes conduzindo os fóruns sem o coach |
