# Quadro de achados do diagnóstico

Descreva o sistema, nunca as pessoas. Na devolução à liderança, leve três achados e três hipóteses, e termine pedindo uma decisão.

| Padrão observado | Evidência | Impacto | Hipótese de causa | Lente (fluxo, decisões, dinheiro, métricas, estrutura, liderança) |
| --- | --- | --- | --- | --- |
| | | | | |
| | | | | |
| | | | | |

## As seis lentes
| Lente | Pergunta central | Onde olhar |
| --- | --- | --- |
| Fluxo | Quanto tempo uma ideia leva até o cliente, e onde ela espera? | Uma demanda real, de ponta a ponta |
| Decisões | Quem decide o quê, e quanto tempo leva? | Fóruns, comitês, alçadas |
| Dinheiro | Como o trabalho é financiado? | Ciclo de planejamento e aprovação de iniciativas |
| Métricas | O que a liderança acompanha toda semana? | Painéis e relatórios usados de verdade |
| Estrutura | Os times estão organizados em torno do cliente ou de especialidades? | Organograma, dependências entre times |
| Liderança | Que comportamentos da liderança aceleram o trabalho? | Reuniões de liderança, conversas individuais |
